# Estrutura do Projeto

## Pastas

## dados/
Responsável por armazenar informações dos temas.

## 📁 interface/
Contém as funções responsáveis pela interação com o usuário, incluindo a exibição dos menus e a seleção de temas e variações disponíveis.

## json/
Arquivos de configuração do projeto.

## 📁 settings/
Contém as funções responsáveis por alterar e salvar as configurações do ThemeManager e do Visual Studio Code.
